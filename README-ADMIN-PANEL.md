# پنل مدیریت ریحون گلد گالری — راهنمای نصب

این پکیج شامل یک **Worker اختصاصی برای پنل مدیریت** (`reyhoon-admin-worker.js`) و یک
**قالب حرفه‌ای CSS** (`assets/admin-theme.css`) برای `admin.html` است. این Worker کاملاً
جدا از Worker اصلی فروشگاه (`reyhoon-gallery-worker.js`) اجرا می‌شود، اما از همان
KV Namespace استفاده می‌کند تا داده‌ها (محصولات، سفارش‌ها، کاربران، تیکت‌ها، کدهای
تخفیف و همکاران ادمین تلگرام) بین پنل وب و ربات تلگرام کاملاً مشترک باشند.

## فایل‌های این پکیج

| فایل | توضیح |
|---|---|
| `reyhoon-admin-worker.js` | کد کامل Worker پنل مدیریت |
| `wrangler-admin.toml` | تنظیمات دیپلوی این Worker |
| `admin.html` | صفحه‌ی پنل مدیریت (به‌روزرسانی‌شده) |
| `assets/admin-theme.css` | قالب/تم اختصاصی پنل مدیریت |

## ۱) ساخت Worker جدید در Cloudflare

1. در Cloudflare Dashboard وارد بخش **Workers & Pages** شو.
2. یک Worker جدید با نام مثلاً `reyhoon-admin` بساز (یا با `wrangler deploy` با فایل
   `wrangler-admin.toml` دیپلویش کن).
3. کد `reyhoon-admin-worker.js` را در آن قرار بده.

## ۲) اتصال به همان KV Namespace وورکر اصلی

در `wrangler-admin.toml`، مقدار `id` زیر `[[kv_namespaces]]` را دقیقاً برابر با
همان `id` ای بگذار که در `wrangler.toml` وورکر اصلی فروشگاه زیر `SHOP_DB` نوشته شده.
اگر با داشبورد Cloudflare کار می‌کنی: Settings → Bindings → KV Namespace Bindings →
همان namespace فروشگاه اصلی را با نام `SHOP_DB` وصل کن.

## ۳) متغیرهای محیطی (Secrets)

از Settings → Variables and Secrets این Worker جدید، سه مقدار زیر را به‌صورت
**Secret** اضافه کن:

- `ADMIN_PANEL_PASSWORD` — رمز عبور ورود به پنل وب (یک رمز قوی انتخاب کن؛ این
  رمز جدا از رمزهای کاربران سایت است)
- `BOT_TOKEN` — همان توکن ربات تلگرام که در وورکر اصلی هم استفاده شده
- `ADMIN_ID` — همان چت‌آیدی مالک ربات که در وورکر اصلی هم استفاده شده

و به‌صورت متغیر عادی (Variable) هم می‌تونی این‌ها رو تنظیم کنی (اختیاری):

- `ADMIN_SESSION_HOURS` — مدت اعتبار نشست ورود، به ساعت (پیش‌فرض ۱۲)
- `ADMIN_ALLOWED_ORIGIN` — دامنه‌ی مجاز CORS (پیش‌فرض `*`؛ بهتره دامنه‌ی سایتت
  رو بگذاری، مثلاً `https://bytelabpro.xyz`)

## ۴) وصل کردن admin.html به Worker جدید

در پایین فایل `admin.html`، خط زیر را با آدرس واقعی Worker جدید جایگزین کن:

```js
const API_BASE = "https://reyhoon-admin.YOUR_SUBDOMAIN.workers.dev";
```

## ۵) تست

1. `admin.html` را باز کن، با رمز `ADMIN_PANEL_PASSWORD` وارد شو.
2. از بخش «مدیریت ربات تلگرام» یک همکار اضافه کن یا پیام همگانی بفرست — باید در
   تلگرام دریافت بشه.
3. یک محصول جدید بساز — باید بلافاصله در گالری سایت اصلی هم دیده بشه (چون از
   همون KV می‌خونه).
4. از منوی «لاگ فعالیت‌ها» ببین که عملیات‌هات ثبت شده باشن.

## نکات امنیتی

- تلاش‌های ناموفق ورود محدود شده: بعد از ۵ بار رمز اشتباه، IP به مدت ۱۵ دقیقه
  موقتاً قفل می‌شه.
- نشست ورود (Token) در KV با انقضای خودکار ذخیره می‌شه؛ با خروج از پنل یا
  تمام‌شدن زمان، باید دوباره وارد بشی.
- توصیه می‌شه `ADMIN_ALLOWED_ORIGIN` رو روی دامنه‌ی واقعی سایتت تنظیم کنی تا
  فقط از همون دامنه بشه به API درخواست زد.
